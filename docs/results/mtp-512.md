# Native MTP: пять запросов × 512 токенов

Apple M2 Pro, 16 GB, Qwen3.5-9B MLX 4-bit. Greedy, fresh cache, один warmup, wired memory, caffeinate di.

| Прогон | Prefill mean ± SD, tok/s | Decode mean ± SD, tok/s | Peak allocated GB |
|---|---:|---:|---:|
| MLX-VLM baseline до | 178.61 ± 29.77 | 34.81 ± 0.47 | 5.48 |
| Native MTP K3 | 181.64 ± 31.79 | 41.58 ± 0.96 | 5.62 |
| MLX-VLM baseline после | 151.10 ± 25.33 | 30.30 ± 4.39 | 5.48 |

MTP / более быстрый baseline до: **1.194× (+19.4%)** по средним decode. Принято **1606 / 1899 (84.57%)** draft-токенов.

Проверено точное совпадение всех **2560 выходных token IDs** MTP с каждым из двух baseline. JSON хранит parity по запросам и SHA-256 массивов IDs; полные массивы не включены в компактную публикацию.

**Ограничение реализации:** штатный MTP использует оптимизированный quantized projection/argmax path, тогда как записанный baseline материализует полные logits и затем вычисляет argmax. Эта серия сравнивает реализации целиком и не изолирует вклад одного лишь speculative-алгоритма.

Повторный baseline замедлился; больший выигрыш относительно него не выбран основным результатом. Все три прогона выполнены от батареи. Температура и частоты не фиксировались. SD — разброс пяти разных запросов, а не доверительный интервал. Совпадение токенов проверено только для этой выборки.
